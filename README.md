# API PB Studio

API REST para la gestión de usuarios de PB Studio, construida con:
- Node.js
- Express
- TypeScript
- Firebase/Firestore

## Instalación

```bash
npm install
```

## Configuración

1. Añadir archivo de credenciales de Firebase en `src/config/`
2. Crear archivo `.env` con las variables de entorno necesarias

## Desarrollo

```bash
npm run dev
```

## Producción

```bash
npm run build
npm start
```
